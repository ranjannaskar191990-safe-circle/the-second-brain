# The Second Brain

Mobile-first multilingual personal diary and organizer.

## Current features
- Speak / type / upload capture
- Bengali, Hindi, English and mixed-language classification
- Finance, Railway Work, Tasks, Projects and Personal categories
- Railway KM-range extraction
- Preview before save
- Offline browser queue

## Roadmap
- Live Google Sheet sync after confirmation
- PDF, DOCX, XLSX and image extraction
